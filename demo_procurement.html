An AI agent just approved a $12,480 purchase order.

Six months from now, in a dispute with the vendor, you will be asked to prove exactly what the agent approved. Today the answer is an application log — a mutable row in a database that anyone with write access can change, with nothing to show it was not changed.

What this demo shows

Hermes signs the agent's action into a COSE_Sign1 receipt using an Ed25519 key held locally. An auditor with only the public key can confirm the exact payload that was approved — and any edit to that payload, however small, breaks verification.

Every digest, signature, and verification result on the next three screens comes from live calls to this Hermes instance. Nothing here is precomputed.
